# Генератор геометрии Т-образного микрофлюидного реактора

Инструмент на Python/VTK (+ CadQuery/OpenCASCADE для STEP) для параметрической
генерации геометрии лабораторного Т-образного микрофлюидного реактора
генерации капель (см. чертёж, п.1). Параметры соответствуют чертежу и могут
варьироваться из командной строки — под последующее исследование влияния
геометрии на поведение реактора (генерацию капель, перепад давления и т.д.).

## Файлы

| Файл | Назначение |
|---|---|
| `geometry_core.py` | Единственный источник геометрии (параметры, Т-контур, боксы крышек). Не зависит ни от VTK, ни от CadQuery. |
| `vtk_backend.py` | Строит полигональную (STL) геометрию через VTK. |
| `step_backend.py` | Строит точную BREP-геометрию (STEP) через CadQuery/OpenCASCADE. |
| `generate_reactor.py` | CLI-скрипт, вызывающий оба бэкенда и сохраняющий результат. |

## Запуск

```bash
# параметры по умолчанию = точно как на чертеже (L1=10, L2=8, L3=30, w=0.2, wd=0.1, h=0.1 мм)
python3 generate_reactor.py --outdir out

# варьирование параметров, например для исследования влияния
# длины дозирующего канала на размер генерируемых капель:
python3 generate_reactor.py --L2 12.0 --outdir out_L2_12
python3 generate_reactor.py --w 0.25 --wd 0.12 --outdir out_w025

# только STL или только STEP:
python3 generate_reactor.py --stl-only --outdir out_stl
python3 generate_reactor.py --step-only --outdir out_step
```

Все размеры задаются в **миллиметрах**. Параметры со значениями по умолчанию:

| Параметр | Обозначение на чертеже | Значение по умолчанию |
|---|---|---|
| `--L1` | L1 | 10 мм |
| `--L2` | L2 | 8 мм |
| `--L3` | L3 | 30 мм |
| `--w`  | w  | 0.2 мм (200 мкм) |
| `--wd` | wd | 0.1 мм (100 мкм) |
| `--h`  | h  | 0.1 мм (100 мкм) |
| `--cap-thickness` | — (не с чертежа) | 0.3 мм |

## Что генерируется

* `reactor_main_body.stl` / `.step` — основное тело канала реактора.
* `cap_inlet_1.stl` / `.step` — крышка входа 1 (левый торец главного канала).
* `cap_inlet_2.stl` / `.step` — крышка входа 2 (торец бокового/дозирующего канала).
* `cap_outlet.stl` / `.step` — крышка выхода (правый торец главного канала).
* `params.json` — использованные параметры (для трассируемости при
  варьировании параметров в серии расчётов).

### Важное отличие STL и STEP основного тела

* **STL (VTK)** — основное тело представляет собой **открытую** (не
  замкнутую) оболочку: стенки и дно/крышку канала, но с тремя
  **сквозными отверстиями** ровно там, где к каналу подходят входы/выход.
  Отдельные STL-крышки в точности закрывают эти отверстия. Такое
  разбиение на отдельные STL-файлы — стандартная практика при подготовке
  геометрии к объёмному построению сетки для CFD (например, workflow
  `snappyHexMesh` в OpenFOAM или аналоги): стенки канала помечаются как
  `wall`, а каждая крышка — как отдельный именованный патч
  (`inlet_1` / `inlet_2` / `outlet`) для граничных условий. Вместе тело
  и три крышки образуют полностью замкнутый объём.

* **STEP (CadQuery/OpenCASCADE)** — основное тело представляет собой
  **точный замкнутый (watertight) твердотельный** BREP-объект (проверено
  через `.isValid()` и сверку объёма аналитическим расчётом). Торцы портов
  здесь — обычные плоские грани твёрдого тела. Крышки — это отдельные
  тонкие BREP-параллелепипеды, примыкающие вплотную к этим торцам снаружи
  (толщиной `--cap-thickness`), которые удобно использовать как
  самостоятельные детали сборки (переходники под трубки/фитинги, или как
  геометрические маркеры для последующей разметки граничных условий в
  CAD/CAE-системе). Если вам нужен сквозной (открытый) STEP-канал —
  соответствующие грани легко вырезать в любой CAD-системе (SolidWorks,
  FreeCAD и т.п.) буленовым вычитанием объёма крышки из тела.

Такое решение объясняется разной природой форматов: STL — сеточный формат,
для CFD естественно сразу задавать открытые границы; STEP — точный
CAD-формат, для которого «твёрдое тело» как самостоятельный, валидный
солид гораздо удобнее для дальнейшей работы в CAD (сборки, чертежи,
изготовление формы/пресс-формы и т.п.).

## Допущения при интерпретации чертежа

1. Размеры `L1`/`L3` отсчитаны от торцов главного канала до оси (центра)
   Т-образного стыка; `L2` отсчитан от торца бокового канала до дальней
   (наружной) стенки главного канала — это соответствует положению
   выносных линий размеров на чертеже.
2. Высота (глубина) канала `h` одинакова во всех трёх ветвях (согласно
   сечению А-А чертежа) — поэтому всё тело реактора строится как одна
   призма над плоским Т-образным контуром, а не как объединение
   отдельных 3D-объёмов.
3. Угол между каналами — жёстко 90°, как показано на чертеже (для
   пилотного реактора №2 с фокусировкой 45° потребуется отдельный,
   более сложный генератор — обращайтесь, если он тоже нужен).

## Проверка корректности геометрии

В скрипте предусмотрена базовая диагностика (`check_manifold` в
`vtk_backend.py`): подсчёт открытых рёбер сетки основного тела — должно
быть ровно 12 (по 4 на каждый из 3 портов), сгруппированных в 3 отдельных
контура, точно совпадающих по расположению и размеру с портами. Для STEP
дополнительно проверяется валидность твёрдого тела средствами
OpenCASCADE и аналитическое соответствие объёма.
